파이썬 버전은 반드시 3.12를 사용

1) venv 설치
python3.12 -m venv .venv

2) west 설치
python3.12 -m pip install west

캐시 오류 발생 시
python3.12 -m pip install --no-cache-dir west

3) zephyr 설치 및 업데이트
west init -m https://github.com/zephyrproject-rtos/zephyr zephyrproject
cd zephyrproject
west update

4) 파이썬 의존성 설치
python3.12 -m pip install @((west packages pip) -split ' ')

5) export
west zephyr-export

6) sdk 설치 (관리자 권한 없어야 됨)
west sdk install

7) board.cmake에 다음 추가
include(${ZEPHYR_BASE}/boards/common/stlink_gdbserver.board.cmake)

8) 빌드시 compile_commands.json 생성
west config build.cmake-args -- -DCMAKE_EXPORT_COMPILE_COMMANDS=ON

9) c_cpp_properties.json 작성
{
    "configurations": [
        {
            "name": "Zephyr STM32H743",
            "compileCommands": [
                "${workspaceFolder}/build/compile_commands.json"
            ]
        }
    ],
    "version": 4
}
